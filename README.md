# Lagoon Project Generator

Lagoon Project Generator is a web tool to help you quickly set up infrastructure configuration files for Amazee.io's Lagoon platform.

## Features

- Generate `.lagoon.yml` and `docker-compose.yml` files.
- Customize services (CLI, Nginx, PHP, etc.).
- Download configurations as a ZIP file.

## Deployment

This project is hosted on **Cloudflare Pages**.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```

## Build

To build the project for production:
```bash
npm run build
```
